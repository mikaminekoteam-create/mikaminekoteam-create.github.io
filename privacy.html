プライバシーポリシー

このプライバシーポリシーは、三神猫（以下「私たち」）が運営する「三神猫 YouTube投稿ツール」（以下「本ツール」）で、Googleのユーザーデータをどう扱うかを説明するものです。

1. 本ツールの目的

本ツールは、私たちが自分たちのYouTubeチャンネルに動画を投稿し、チャンネルの状況を確認するための内部向けツールです。一般の方には提供していません。

2. 取得するデータ

Googleアカウントでの許可（OAuth）を通じて、次のデータにアクセスします。

  • YouTubeチャンネルの情報（チャンネル名、チャンネルID、動画の一覧など）：youtube.readonly
  • 動画のアップロード（動画ファイル、タイトル、説明文などを送ること）：youtube.upload
  • YouTubeアナリティクスの数値（再生回数、視聴時間など）：yt-analytics.readonly
  • 上記を使うための認証情報（アクセストークン、更新トークン）

Googleアカウントのパスワードは受け取りません。

3. データの使い道

  • 私たちが作った動画を、自分たちのチャンネルにアップロードするため
  • 投稿した動画とチャンネルの状況を確認するため
  • 分析データを見て、今後の動画づくりの参考にするため

上記以外の目的には使いません。広告の配信や、データの販売にも使いません。

4. 第三者への提供

取得したデータを第三者に販売、譲渡、共有することはありません。ただし、法令にもとづいて開示を求められた場合を除きます。

5. 保存場所と保存期間

認証情報は、私たちが管理する作業用のコンピューター上のファイルにだけ保存し、運営メンバー以外は読めないようにしています。分析データは、チャンネル運営の記録として、同じく私たちが管理する場所に保存します。不要になったデータは削除します。

6. 削除の方法

  • Googleアカウントの「サードパーティ製のアプリとサービス」から本ツールのアクセスを取り消すと、本ツールはそれ以降データにアクセスできなくなります。
  • 保存している認証情報や分析データの削除を希望する場合は、下記の連絡先までメールでご連絡ください。確認のうえ削除します。

7. Google API Services User Data Policyへの準拠

本ツールがGoogle APIから受け取った情報の利用と、他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

あわせて、YouTube APIサービスを利用しているため、YouTube利用規約とGoogleプライバシーポリシーが適用されます。

8. 変更

このポリシーを変更する場合は、このページを更新してお知らせします。
